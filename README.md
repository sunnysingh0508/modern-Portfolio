## 🚀 Tech Stack

- **Frontend**: React 19, JavaScript (ES6+), TypeScript, Tailwind CSS v4, Framer Motion, Lucide Icons
- **Backend & Cloud**: Python, MongoDB, Vercel, Render
- **Tools**: Git & GitHub, VS Code, Tally, MS Office

## 📁 Sections Included

- **Hero**: Clean standing portrait presentation with smooth animated intro
- **About**: Academic background at LPU, finance management experience, and key impact metrics
- **Skills**: Categorized skill stacks across Web Dev, Programming, Cloud & Tools, and Languages
- **Projects / Experience**: Financial data management, 24h Web-A-Thon hackathon, Next.js web applications, and edtech frameworks
- **Certificates**: Interactive full-resolution credentials suite (Tech Veda, ARENA Hackathon, IBM AI & Web Dev, Times Foundation, LYNQUP Prompt Builder, ADCA)
- **Contact**: Working message form, direct mail, and LinkedIn connectivity

## 🛠️ Local Development

```bash
# Clone repository
git clone https://github.com/sunnysingh0508/modern-Portfolio.git

# Navigate into project directory
cd modern-Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```
